# Berna v7.1 – GitHub Pages düzeltmesi

Bu paket GitHub deposunun **kök dizinine** yüklenmek üzere hazırlanmıştır. Görsel dosyaları da kök dizindedir; bu nedenle `assets/` klasörü gerekmez.

## Kurulum

1. Depodaki eski dosyaların yerine bu paketteki tüm dosyaları yükleyin.
2. GitHub Pages kaynağı `main` ve `/ (root)` olarak kalsın.
3. Yayınlandıktan sonra sayfada `Ctrl + F5` yapın. Gerekirse site verilerini temizleyip tekrar açın.
